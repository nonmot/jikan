## 方針

- 管理セッションは割当・依存関係・検証結果の管理を担当し、実装は各TODO専用のHerdr Codexエージェントが行う。
- 同一チェックアウトで作業し、担当外ファイルの変更を避ける。実装完了後、コミット・PR反映は後続の依頼で実施する。
- `list` は当日既定、全件表示は `--all`。タグ追加は `--tag`、ID指定の互換オプションは残す。
- 日時は設定タイムゾーンで扱い、CSV標準出力は純粋なCSVにする。
- 子エージェントは `--no-daemon` で起動する。確認済み管理ペインは `w11:p2`（ライブ出力がこの会話と一致）。継承された `w8:p9` は使用しない。
